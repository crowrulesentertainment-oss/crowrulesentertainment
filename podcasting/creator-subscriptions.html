Billing architecture

1. Your CrowRules session authenticates the request.

2. Supabase validates the creator plan and account relationship.

3. Stripe Checkout handles recurring billing.

4. Stripe webhook confirms the subscription in Supabase.

5. The database trigger keeps creator subscriber counts synchronized.

Stripe secret keys are never placed in GitHub Pages JavaScript.
