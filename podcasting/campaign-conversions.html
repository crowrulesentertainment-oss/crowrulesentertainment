Sponsor integration guide


Endpoint
https://cevylpnoexugwgygvtgu.supabase.co/functions/v1/podcast-campaign-conversions

Send an HTTPS POST with the campaign key in the Authorization header. Example request:


POST /functions/v1/podcast-campaign-conversions
Authorization: Bearer crcv_YOUR_PRIVATE_KEY
Content-Type: application/json

{
  "action": "record_conversion",
  "event_id": "order-10482",
  "event_type": "purchase",
  "amount": 49.95,
  "currency": "USD",
  "event_at": "2026-11-02T19:30:00Z"
}


Required: unique event_id (1–160 characters). Optional: event_type (letters, numbers, underscores, hyphens), amount, currency (USD/CAD/GBP/EUR), event_at (within the last 366 days). If your sponsor integration cannot send a sale value, send amount 0. The response returns verified true when recorded and duplicate true when that event_id was already received.


Security: keep the key on the sponsor's server only. Never embed it in a website, browser JavaScript, mobile app, email, or public source repository. Do not send names, email addresses, phone numbers, addresses, or payment-card information. Revoke a key by generating a replacement.
